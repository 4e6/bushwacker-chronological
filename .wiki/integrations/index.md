# Integration

* [Supadata transcript API](supadata.md) - The subtitle fallback used when yt-dlp is bot-blocked; pinned to native mode to stay in the free tier.
* [YouTube Data API (OAuth)](youtube-data-api.md) - The OAuth Data API path used from CI for durations and the deterministic playlist insert.
* [YouTube InnerTube (logged-in browser)](youtube-innertube.md) - Reading and mutating the playlist via YouTube's internal InnerTube API from the signed-in browser session.
